# هلا — مساعد سطح مكتب لويندوز

مساعد يُستدعى بالاسم، يجيب بصوت عالٍ أو نصًا، ينظر إلى شاشتك عندما تطلب، يتذكر ما تقوله له، وينفّذ مهام بسيطة بعد موافقتك.
مشروع أصلي بهوية مستقلة، مبني على Python وواجهة Claude البرمجية.

## المزايا
| الميزة | كيف تعمل |
|---|---|
| الاستدعاء بالاسم | قل «هلا» (أو `hala`) من أي مكان، أو اضغط `Ctrl+Alt+H` |
| السؤال الصامت | `Ctrl+Alt+Space` ثم اكتب. زر `Tab` يبدّل بين «عام» و«الشاشة» |
| فهم الشاشة | في وضع «الشاشة» تُلتقط لقطة تُرسل مع سؤالك فقط ولا تُحفظ |
| الذاكرة | قل أو اكتب «تذكّر أن موعدي الخميس» فتُحفظ في `~/.hala/memory.json` |
| وضع التخفّي | `Ctrl+Shift+I`: لا ذاكرة ولا سجل محادثة أثناء تفعيله |
| الإجراءات | فتح تطبيقات من قائمة بيضاء أو روابط https، وتطلب موافقتك دائمًا |

لا توجد أي إجراءات حذف أو إرسال أو دفع في الكود عمدًا.

## التشغيل
1. ثبّت Python 3.10 أو أحدث على ويندوز.
2. `pip install -r requirements.txt`
   (إن فشل PyAudio: `pip install pipwin` ثم `pipwin install pyaudio`)
3. أنشئ مفتاحًا من Anthropic Console ثم في PowerShell:
   `setx ANTHROPIC_API_KEY "مفتاحك"` وأعد فتح الطرفية.
4. `python hala_main.py` — ستظهر أيقونة في شريط المهام.

## التخصيص (`config.py`)
- `WAKE_WORDS` و`ASSISTANT_NAME`: غيّر الاسم كما تشاء.
- `SPEECH_LANG`: `ar-SA` للعربية أو `en-US` للإنجليزية.
- `MODEL`: النموذج المستخدم.
- الاختصارات: `HOTKEY_*`.

## ملاحظات صريحة
- التعرف على الكلام وكلمة الاستدعاء يستخدمان خدمة Google عبر SpeechRecognition، أي أن الصوت يخرج من جهازك. لاستدعاء محلي بالكامل بدّل `wake_loop` في `voice.py` بمحرك مثل openWakeWord أو Porcupine.
- الصوت المنطوق يعتمد على أصوات ويندوز المثبتة؛ للعربية ثبّت حزمة صوت عربي من إعدادات النظام.
- لم تُجرَّب الحزمة على جهاز ويندوز حقيقي في بيئة الإنشاء، فقد تحتاج إلى تعديلات صغيرة.

## هيكل الملفات
`hala_main.py` الواجهة والتشغيل • `brain.py` الاتصال بـ Claude • `voice.py` الصوت • `screen.py` لقطة الشاشة • `memory.py` الذاكرة • `actions.py` الإجراءات الآمنة • `config.py` الإعدادات
